# Як додати проєкт на сторінку «Проєкти»

Сторінка `/projects/` (і `/en/projects/`) сама читає файл **`data/projects.json`**.
Щоб додати проєкт, достатньо двох кроків на GitHub — нічого збирати чи запускати не треба.

## 1. Завантажте обкладинку

1. Відкрийте репозиторій на GitHub → папка **`projects/img/`**.
2. **Add file → Upload files**, перетягніть картинку.
   - формат: `.webp` або `.jpg`, **1280×720** (16:9), до ~300 КБ;
   - назва латиницею: `nazva-proektu.webp`.
3. Внизу оберіть **Create a new branch** (наприклад `add-nazva-proektu`) → **Propose changes**.

> Скриншот сайту найпростіше зробити в Chrome: DevTools → ⌘⇧P → «Capture screenshot» при ширині вікна 1440 px.

## 2. Додайте запис у `data/projects.json`

1. Перейдіть у **ту саму гілку**, відкрийте `data/projects.json` → іконка олівця ✏️.
2. Скопіюйте шаблон нижче й вставте **після** останнього `}` у списку `"projects"`, поставивши **кому** перед ним.
3. **Commit changes** у ту саму гілку → **Create pull request**.
4. GitHub автоматично перевірить файл (зелена ✔️ = все добре). Хтось із команди переглядає й тисне **Merge**.

```json
{
  "slug": "nazva-proektu",
  "title": "Назва проєкту",
  "type": "client",
  "category": "business",
  "year": 2026,
  "author": "Ім'я",
  "cover": "projects/img/nazva-proektu.webp",
  "url": "https://site-klienta.com",
  "tags": ["WordPress", "CRM"],
  "summary": {
    "uk": "Коротко: що зробили і для кого (1–2 речення).",
    "en": "Short description in English (1–2 sentences)."
  }
}
```

### Поля

| Поле | Обов'язкове | Значення |
|---|---|---|
| `slug` | так | унікальний ідентифікатор: малі латинські літери, цифри, дефіс |
| `title` | так | назва, як показувати на картці |
| `type` | так | `client` — реальний клієнт, `concept` — концепт / демо |
| `category` | так | `business`, `landing`, `ecommerce`, `app`, `bot`, `other` |
| `cover` | так | шлях до картинки (`projects/img/...`) або повне посилання |
| `summary` | так | опис `uk` і `en` |
| `url` | бажано | куди веде картка: сайт клієнта або сторінка всередині нашого сайту |
| `url_en` | ні | окреме посилання для англійської версії |
| `year`, `author` | ні | рік, хто з команди робив |
| `tags` | ні | теги: список `["WordPress", "CRM"]` або окремо для мов `{"uk": [...], "en": [...]}` |
| `hidden` | ні | `true` — тимчасово сховати проєкт, не видаляючи |

Проєкти сортуються: новіші роки вище, клієнтські — перед концептами того ж року.

### Перевірити локально (необов'язково)

```bash
python3 _build/validate_projects.py
python3 -m http.server 5173   # і відкрити http://localhost:5173/projects/
```

### Важливо

- Додаючи клієнтський проєкт, переконайтеся, що клієнт не проти публікації (або це прописано в договорі).
- Не завантажуйте в репозиторій паролі, доступи чи конфіденційні дані клієнтів.
