# Заявки з сайту → Google Таблиця + Telegram + пошта

Форма на сайті надсилає заявку в Google Apps Script. Скрипт:
- додає рядок у Google Таблицю «Заявки» (дата, тема, ім'я, контакт, бюджет, повідомлення, мова, сторінка, UTM, статус);
- надсилає повідомлення в Telegram (вам або в групу команди);
- дублює лист на пошту.

Усе безкоштовно. Налаштування — ~10 хвилин, робиться один раз.

## ⚡ Швидкий старт без Telegram (5 хв)

Telegram можна підключити пізніше — без бота скрипт просто записує заявку в таблицю й надсилає лист.

1. **sheets.new** під акаунтом adv.development.studio@gmail.com → назва «ADV — Заявки».
2. **Розширення → Apps Script** → видалити все в `Code.gs` → вставити вміст [`Code.gs`](Code.gs) → 💾 **Зберегти**.
3. ⚙️ **Налаштування проєкту → Властивості скрипту → Додати властивість:** `NOTIFY_EMAIL` = `adv.development.studio@gmail.com` → **Зберегти**.
4. Повернутися в редактор `< >` → у списку функцій обрати **`sendTestLead`** → **▶ Виконати** → дозволити доступ (див. Крок 3, пункт 2 нижче). У таблиці з'явиться аркуш «Заявки» з тестовим рядком, на пошту прийде лист.
5. **Розгортання → Нове розгортання → Веб-застосунок**, «Виконувати від імені: Я», «Хто має доступ: Усі» → **Розгорнути** → скопіювати URL, що закінчується на `/exec`, і надіслати в чат розробки.

Щоб пізніше додати Telegram — пройдіть Кроки 1 і 3 нижче й додайте властивості `TELEGRAM_TOKEN` та `TELEGRAM_CHAT_ID`. Перерозгортати чи міняти сайт не потрібно.

---

## Крок 1. Telegram-бот (3 хв)

1. У Telegram відкрийте **@BotFather** → `/newbot`.
2. Назва: `ADV Заявки`, username: наприклад `adv_leads_bot` (має закінчуватися на `bot`).
3. BotFather надішле **токен** вигляду `1234567890:AAH...` — збережіть його, нікому не пересилайте.
4. Куди слати заявки:
   - **лише вам** — відкрийте свого бота й натисніть **Start**;
   - **усій команді** — створіть групу в Telegram, додайте туди бота й колег, напишіть у групі будь-яке повідомлення.

## Крок 2. Таблиця і скрипт (4 хв)

1. Відкрийте **sheets.new** (нова Google Таблиця) під акаунтом **adv.development.studio@gmail.com**. Назвіть її «ADV — Заявки».
2. Меню **Розширення → Apps Script**.
3. Видаліть усе у файлі `Code.gs` і вставте вміст файлу [`Code.gs`](Code.gs) з цієї папки. Натисніть 💾 **Зберегти**.
4. Ліворуч ⚙️ **Налаштування проєкту** → внизу **Властивості скрипту** → **Додати властивість** тричі:

   | Властивість | Значення |
   |---|---|
   | `TELEGRAM_TOKEN` | токен від BotFather |
   | `NOTIFY_EMAIL` | `adv.development.studio@gmail.com` |
   | `TELEGRAM_CHAT_ID` | поки залиште порожнім — дізнаємось у наступному кроці |

   → **Зберегти властивості скрипту**.

## Крок 3. Дізнатися chat id (1 хв)

1. Поверніться в редактор (іконка `< >` ліворуч), угорі у списку функцій оберіть **`showTelegramChats`** → **▶ Виконати**.
2. Перший запуск попросить дозвіл: **Переглянути дозволи** → оберіть акаунт → «Google не перевірив цей додаток» → **Додатково** → **Перейти до проєкту (небезпечно)** → **Дозволити**. Це ваш власний скрипт — так Google показує для всіх нових скриптів.
3. Унизу в «Журналі виконання» з'явиться рядок на кшталт `-1001234567890 ← ADV Team (supergroup)` або `123456789 ← Дарʼя (private)`.
4. Скопіюйте число (разом із мінусом, якщо він є) у властивість **`TELEGRAM_CHAT_ID`**. Кілька чатів — через кому.

## Крок 4. Перевірка (30 с)

Оберіть функцію **`sendTestLead`** → **▶ Виконати**. Мають з'явитися: рядок у таблиці (аркуш «Заявки»), повідомлення в Telegram, лист на пошту. Тестовий рядок потім можна видалити.

## Крок 5. Опублікувати (1 хв)

1. Угорі праворуч **Розгортання → Нове розгортання**.
2. ⚙️ біля «Виберіть тип» → **Веб-застосунок**.
3. Опис: `ADV form`. **Виконувати від імені:** *Я*. **Хто має доступ:** *Усі*.
4. **Розгорнути** → скопіюйте **URL веб-застосунку** (закінчується на `/exec`).
5. Надішліть цей URL у чат розробки — його буде вписано в `_build/build.py` (`FORM_ENDPOINT = "..."`), сайт перезбирається і пушиться.

> «Хто має доступ: Усі» означає лише, що на цю адресу можна **надіслати** заявку. Прочитати таблицю чи токен через неї неможливо.

---

## Якщо потім змінюєте `Code.gs`

**Розгортання → Керувати розгортаннями → ✏️ → Версія: Нова версія → Розгорнути.** URL залишається тим самим, на сайті нічого міняти не треба.

## Захист від спаму (вже вбудовано)

- приховане поле-пастка, яке заповнюють лише боти;
- заявки, надіслані швидше ніж за 2,5 с після відкриття сторінки, ігноруються;
- не більше 5 заявок з одного контакту за 10 хвилин;
- значення, що починаються з `=`, `+`, `-`, `@`, записуються як текст (захист від формул у таблиці).

## Конфіденційність

Заявки містять персональні дані. Доступ до таблиці давайте лише команді; строки зберігання й передача даних Google/Telegram описані в Політиці конфіденційності сайту.
